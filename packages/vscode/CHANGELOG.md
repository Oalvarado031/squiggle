# Changelog

## 0.1.0

First release.

- Squiggle language support for `.sqg` files: highlighting generated from the Squiggle vocabulary, comments, bracket matching, indent on Enter after block lines, and folding by indentation.
- Snippets for every block, one per shape command, and `piece` to start a new animated piece.
- `Squiggle: Open in Squiggle Studio` opens the selection or the whole file in the studio (title bar, right-click menu, Command Palette).
- Post counter in the status bar (`214 / 280`), counted the way X counts characters.
- `squiggle.studioUrl` setting.
